# Iconos PWA

Este directorio debe contener los siguientes iconos para la PWA:

## Iconos Requeridos

### Favicon
- `favicon-16x16.png` - 16x16 píxeles
- `favicon-32x32.png` - 32x32 píxeles

### Apple Touch Icons
- `apple-touch-icon.png` - 180x180 píxeles

### Android Chrome Icons
- `android-chrome-192x192.png` - 192x192 píxeles
- `android-chrome-512x512.png` - 512x512 píxeles

### Shortcut Icons (Opcionales)
- `url-shortcut.png` - 96x96 píxeles
- `wifi-shortcut.png` - 96x96 píxeles
- `contact-shortcut.png` - 96x96 píxeles

## Generación de Iconos

Puedes generar estos iconos usando herramientas online como:

1. **Favicon.io** - https://favicon.io/
2. **RealFaviconGenerator** - https://realfavicongenerator.net/
3. **PWA Asset Generator** - https://github.com/onderceylan/pwa-asset-generator

## Especificaciones

- **Formato**: PNG
- **Fondo**: Transparente o sólido
- **Estilo**: Consistente con el diseño de la app
- **Colores**: Usar los colores de la marca (#2563eb)

## Diseño Sugerido

El icono principal debe ser un código QR estilizado con:
- Cuadrados negros sobre fondo blanco
- Bordes redondeados
- Logo central pequeño (opcional)
- Colores de la marca en elementos decorativos
